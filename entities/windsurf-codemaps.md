# Windsurf Codemaps

Windsurf（原 Codeium）推出的 Codemaps 功能，为 AI 编程助手提供代码库的全局视图。

## 概述

- **产品**: Windsurf Editor
- **公司**: Codeium
- **核心功能**: Codemaps（代码地图）
- **定位**: Cursor 竞品，强调"AI-native IDE"

## Codemaps 核心能力

| 能力 | 说明 |
|------|------|
| 全局代码视图 | 可视化代码库结构、依赖关系 |
| 智能跳转 | 点击函数/类直接跳转到定义 |
| 影响分析 | 修改某处代码会影响哪些地方 |
| 上下文感知 | AI 自动理解代码库结构 |

## 与 Graphify 对比

| 维度 | Windsurf Codemaps | Graphify |
|------|-------------------|----------|
| 定位 | IDE 内置功能 | 独立工具 |
| 输入 | 当前打开的项目 | 任意文件夹 |
| 输出 | IDE 内嵌视图 | graph.html 交互网页 |
| 可视化 | 代码结构图 | 知识图谱 |
| 持久化 | 会话内 | 可持久化到 graph.json |
